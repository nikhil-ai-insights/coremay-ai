# 🤝 Contributing

Thank you for your interest in contributing to **Coremay AI**! 🚀

We welcome contributions, suggestions, bug reports, and feature ideas that can help improve the platform.

---

## 📌 How to Contribute

### 1. Fork the Repository

Fork this repository to your GitHub account.

### 2. Clone Your Fork

```bash
git clone https://github.com/YOUR_USERNAME/coremay-ai-commerce.git
```

### 3. Navigate to the Project Directory

```bash
cd coremay-ai-commerce
```

### 4. Create a New Branch

Create a separate branch for your feature or bug fix.

```bash
git checkout -b feature/your-feature-name
```

For bug fixes:

```bash
git checkout -b fix/your-bug-fix
```

### 5. Make Your Changes

Implement your feature, improvement, or bug fix while maintaining clean and readable code.

Please ensure that your changes:

- Follow the existing project structure
- Do not break existing functionality
- Include proper error handling where necessary
- Maintain responsive design
- Follow security best practices
- Do not expose API keys or sensitive credentials

### 6. Test Your Changes

Before submitting your contribution, test the application thoroughly.

Make sure that:

- Authentication works correctly
- User-specific data remains isolated
- Protected routes work properly
- AI features function as expected
- Existing features are not affected

### 7. Commit Your Changes

Write a clear and meaningful commit message.

```bash
git add .
git commit -m "feat: add your feature description"
```

Example:

```bash
git commit -m "feat: add AI product comparison feature"
```

### 8. Push Your Branch

```bash
git push origin feature/your-feature-name
```

### 9. Create a Pull Request

Open a Pull Request from your forked repository to the main Coremay AI repository.

In your Pull Request, please include:

- A clear description of your changes
- The problem your contribution solves
- Screenshots, if UI changes are included
- Any important implementation details

You can contribute by:

- ✨ Suggesting new features
- 🤖 Improving AI capabilities
- 🎨 Improving the user interface
- 📱 Enhancing mobile responsiveness
- 🔒 Improving security

## 🐛 Reporting Bugs

When reporting a bug, please provide:

- A clear description of the issue
- Steps to reproduce the problem
- Expected behavior
- Actual behavior
- Screenshots, if applicable
- Browser or device information

---

## 💡 Feature Requests

Have an idea for Coremay AI?
We would love to hear it!

When submitting a feature request, please explain:

- The problem the feature would solve
- Your proposed solution
- The potential benefit to users or merchants

---

## 🔐 Security Notice

Please do not include sensitive information in issues, pull requests, or commits.

This includes:

- Firebase API secrets
- Razorpay secret keys
- Private authentication credentials
- Personal user information
